# My shelf log

This file supplies the entries on /shelf/. Edit the list between the opening and closing `---` lines. The instructions below are not published. No JSON file needs editing.

## Add an entry

Copy this block into the `entries:` list above. Keep the indentation; keep dates in quotes.

```yaml


  - title: "Title"
    creator: "Author or director name"
    creator_role: "Author"

    medium: "book"
    edition: ""

    status: "Reading"
    status_date: "2026-11-17"
    logged_on: "2026-11-17"

    source: ""
    notes_url: ""

    note: "[Add a note]"
```

- `spine_cast`: optional list of up to two actors for movie spines; the note retains the filmmaker credit.
- `medium`: `book`, `dvd`, or `tv`.
- `creator_role`: `Author` for books, `Director` for films and TV. Multiple directors can be separated with `/`.
- `credit_source`: optional verification URL for author/director/producer credits.
- `publication_source`: optional verification URL for publication/release information; not a personal scribble link.
- `edition`: publication/release date or year plus any season or edition, e.g. `2026 · Season 3 · series`. Use `Year to add` if unconfirmed.
- `status`: `Finished`, `Reading`, `Watching`, or `Forgotten`. Forgotten entries appear only on `/shelf/forgotten/`, with cobwebs. Change it to `Finished` when done and replace `status_date` with the finish date.
- `status_date`: date finished, or date you were reading/watching. Leave `""` if unknown; the shelf displays “date not recorded.” Existing post dates have not been invented as finish dates.
- `status_month`: optional `YYYY-MM` when only the month is known; displayed instead of `status_date`.
- `logged_on`: controls stack order, newest first. It is not displayed as a finish date.
- `source`: optional existing blog post path, e.g. `_posts/random/2026-10-11-tender-hearts.md`.
- `notes_url`: optional URL or site path for “Read my scribbles.” Used when `source` is empty. Leave both empty to omit the link.
- `note`: a line from the linked scribble (formatting removed), shown when opened. If there is no suitable line, use `[Add a note]`.
